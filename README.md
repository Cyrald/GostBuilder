# GostBuilder

[![License: MIT](https://img.shields.io/github/license/Cyrald/md2gost)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)

GostBuilder — настольное приложение, которое преобразует документ в формате Markdown в документ Microsoft Word (`.docx`), оформленный в соответствии с выбранным ГОСТ.

## Назначение

Программа создана для написания с помощью нейросетей больших документов: отчётов, курсовых и научно-исследовательских работ. Для каждого ГОСТ предусмотрен собственный промт, который передаётся нейросети. По этому промту нейросеть формирует все необходимые файлы, они загружаются в GostBuilder, и программа оформляет их в документ по выбранному ГОСТ.

На данный момент реализованы стандарты
1. ГОСТ 7.32-2017.

## Установка

Требуется Python 3.10 или новее. В Linux дополнительно необходим Tkinter: `sudo apt install python3-tk`.

```bash
git clone https://github.com/Cyrald/md2gost.git
cd md2gost
pip install -r requirements.txt
python main.py
```

При первом запуске программа автоматически загружает необходимые компоненты (pandoc и pandoc-crossref, около 40 МБ). Для этого требуется подключение к интернету.

## Использование

1. **Markdown (.md)** — файл с текстом документа, который выдаёт нейросеть в ответ на промт.
2. **.bib файл** — файл с библиографией в формате BibTeX; формируется нейросетью вместе с Markdown-файлом.
3. **Титульный лист** — выберите шаблон из списка или добавьте собственный `.docx`-файл. Вариант «Не использовать» создаёт документ без титульного листа.
4. **Стили тела** — выберите ГОСТ, по которому необходимо оформить документ.
5. Установите при необходимости флажки:
   - **Авто-оглавление (TOC)** — добавляет раздел «Содержание»;
   - **Нумерация разделов** — нумерует разделы в формате `1`, `1.1`, `1.1.1`.
6. Нажмите **«КОНВЕРТИРОВАТЬ»** и укажите место сохранения `.docx`-файла.
7. Предупреждения и ошибки отображаются в журнале в нижней части окна.

> При первом открытии документа Word может предложить обновить поля — подтвердите. Если номера страниц в оглавлении не отобразились, нажмите `Ctrl+A`, затем `F9`.

## Участие в разработке

Каждый ГОСТ в программе реализован в виде отдельного профиля. Если вы хотите добавить новый ГОСТ, ознакомьтесь с [руководством по созданию профилей](resources/styles/README.md) и создайте собственный профиль.
